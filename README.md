# 🐱 泰拉瑞亚猫娘 (neko_terraria)

> 让 AI 猫娘作为**独立玩家**加入你的泰拉瑞亚世界：双轨任务调度、自主行为、复杂多步任务规划与执行、mod 物品合成推演。
>
> 基于 [N.E.K.O](https://project-neko.online) SDK v2 · 支持 tModLoader

---

## ✨ 核心特性

| 🎮 **双轨任务** | 🧠 **复杂任务大脑** | ⚒️ **mod 合成推演** |
|:---:|:---:|:---:|
| 前台有限任务 + 后台长期任务并行 | 想(评估)→处理(规划)→做(执行) | 识别 mod 物品与真实配方 |
| 主人指令随时打断前台 | 虚拟背包推演 + 补救推理 | 缺材料/缺站台都会告诉你 |
| 长期任务自动让路 | 任一步失败即中止汇报 | 中英物品名互相识别 |

| 🗺️ **自主寻路** | ⚔️ **真人级战斗** | 💬 **自然语言** |
|:---:|:---:|:---:|
| 遇坑搭土/钩锁飞越 | 走位拉扯 + 黑名单 | 语音/聊天直接下达 |
| 深坑分段爬升 | 低血自动自救 | 约 26 个 LLM 工具驱动 |

## 🚀 快速开始

### 系统要求

| 组件 | 版本 |
|:-----|:-----|
| N.E.K.O | v0.8.3.2 或更高 |
| 泰拉瑞亚 (Terraria) | 已开服务端/世界 |
| tModLoader | 已载入 `NekoTerrariaLink` mod |
| Python | 3.13+ (插件运行环境) |

### 安装

```
1️⃣  复制 neko_terraria/ 到 N.E.K.O 插件目录下的 plugins/
2️⃣  打开 N.E.K.O → 插件管理 → 启用「泰拉瑞亚猫娘」
3️⃣  在控制面板点击「连接游戏」按钮
4️⃣  用语音/聊天对猫娘说话："去挖 10 个铁矿"
```

### 配置

唯一生效配置在 `plugin.toml` 的 `[neko_terraria]` 段：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `server_host` / `server_port` | `127.0.0.1` / `7777` | Terraria 服务端 |
| `mod_host` / `mod_port` | `127.0.0.1` / `9877` | tModLoader mod 接口 |
| `bot_name` / `bot_password` | `Neko` / 空 | 猫娘登录名 |

> ⚠️ 目录下的 `data/config/settings.json` 当前未被代码读取，改它无效，请以 `plugin.toml` 为准。

### 示例对话

```
💬 "去挖 10 个铁矿"          → 猫娘前往挖掘
💬 "挖完给我"               → 挖到后丢给你
💬 "坑底挖矿然后回地面拿绳子再回来" → 复杂多步任务
💬 "跟着我"                 → 启动长期跟随
💬 "铁锭怎么合成"           → 查询配方与条件
💬 "你在干嘛"               → 汇报当前任务与思考
```

## 🔧 开发指南

本插件遵循 N.E.K.O Mixin 架构规范（`@neko_plugin` 无参、Mixin 不含 `__init__`、`@lifecycle` 用 `id=`、服务传 `self`）。新增功能流程：

1. 建 Mixin 文件（只含方法 + 类常量）
2. 更新 `__init__.py` 导入与继承列表
3. 在主 `__init__` 初始化所需属性
4. 测试验证并删除 `__pycache__`

> 完整规范见 [archive/PLUGIN_ARCHITECTURE_GUIDE.md](./archive/PLUGIN_ARCHITECTURE_GUIDE.md)
