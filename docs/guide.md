# NEKO猫娘AI · 使用指南

## 这是什么？

NEKO猫娘AI 是 N.E.K.O. 的泰拉瑞亚插件。让 AI 猫娘作为**独立玩家**登录你的泰拉瑞亚世界，听你说话、自主挖矿、合成、探索、战斗。

```
你（语音/聊天）→ N.E.K.O AI → 本插件 → Terraria-Bot(7777) + tModLoader Mod(9877) → 泰拉瑞亚世界
```

---

## 前置条件

| 组件 | 说明 |
|------|------|
| Windows 10/11 | 操作系统 |
| N.E.K.O. | AI 伴侣平台，已安装并运行 |
| tModLoader | 已安装（推荐 1.4.4+） |
| **NekoTerrariaLink** mod | 配套 tModLoader mod，需在 tModLoader 中启用并构建 |
| Terraria 服务端 | Terraria-Bot 协议服务端（或通过 TShock/原版服务器） |

### Mod 安装检查清单

- [ ] `ModSources/NekoTerrariaLink/` 目录存在
- [ ] tModLoader 中 **NEKO猫娘AI** mod 已启用（显示猫娘封面）
- [ ] 构建无报错（0 errors）
- [ ] 游戏内 mod 列表显示 NEKO猫娘AI 为已加载状态

---

## 第一步：启动插件

1. 打开 N.E.K.O. → 插件管理面板
2. 找到 **泰拉瑞亚猫娘**，点击启用
3. 确认状态变为绿色「已启用」（不再显示加载失败）

---

## 第二步：连接游戏

1. 确保 **Terraria 服务端已运行**（Terraria-Bot 或 TShock）
2. 确保 **tModLoader 已载入 NekoTerrariaLink mod**
3. 打开本插件的**控制面板**，点击 **「连接游戏」**
4. 猫娘以玩家 `Neko` 登录世界，状态条显示「已连接」即就绪

> 连接成功后，猫娘会自动开始扫描周围环境、注册 mod 物品、学习配方。

---

## 第三步：用语言指挥猫娘

直接用语音或聊天对 N.E.K.O 说话即可，常用说法：

### 基础指令

| 你想做什么 | 可以这样说 |
|-----------|-----------|
| 下达目标 | "去挖 10 个铁矿" "给我做把铁镐" "探索一下附近" |
| 多步任务 | "坑底挖矿，然后回地面拿绳子，再回来" |
| 只评估不做 | "你能不能从坑底爬上来？" "做这个需要什么？" |

### 物品交互

| 你想做什么 | 可以这样说 |
|-----------|-----------|
| 要物品 | "把铁锭给我" "把治疗药水丢给我" |
| 存取箱子 | "收进箱子" "从箱子拿绳子" |
| 查询背包 | "你背包里有什么？" "治疗药水在哪？" |
| 合成查询 | "铁锭怎么合成？" "做钛金套装要什么？" |

### 移动与行动

| 你想做什么 | 可以这样说 |
|-----------|-----------|
| 移动 | "传送到 (x,y)" "爬到 (x,y)" "跟着我" |
| 长期任务 | "一直挖铁" "守在这里" |
| 停止 | "别跟了" "不用挖了" "停下" |

### 小提示

- **随时打断**：你新的指令可以随时打断猫娘当前正在做的事
- **复杂任务**：猫娘会先「想」再「做」，遇到卡点会自动停下并向你汇报
- **自主寻路**：会自动绕障、搭路爬坑，深坑也能分段爬回地面
- **主动行为**：你不说话时，猫娘也会根据当前情况自主行动（挖矿、探索、整理背包等）

## 控制面板说明

打开插件面板后，你会看到以下功能区域：

### 连接控制

| 按钮 | 作用 |
|------|------|
| **连接游戏** | 登录泰拉瑞亚世界 |
| **刷新状态** | 更新 HP / MP / 位置等数据 |
| **断开** | 让猫娘退出世界 |

### 状态数据

| 数据 | 说明 |
|------|------|
| 生命值 (HP) | 猫娘当前血量 |
| 法力值 (MP) | 猫娘当前法力 |
| 当前目标 | 猫娘正在执行的任务描述 |

### 快捷操作

| 按钮 | 作用 |
|------|------|
| **查看背包** | 显示快捷栏 / 装备栏 / 主背包 |
| **箱子清单** | 枚举附近箱子及内容物 |
| **行为日志** | 查看猫娘近期「想 / 做」的记录 |

### 其他标签页

- **背包 & 物品**：详细查看所有携带物品
- **箱子**：附近箱子的位置和内容
- **行为日志**：完整的时间线日志（带时间戳）
- **已识别 Mod**：猫娘认识的 mod 及其物品数量

## 常见问题

### 连接相关

| 现象 | 解决方法 |
|------|---------|
| 点「连接游戏」无反应 | 确认 Terraria 服务端已运行、mod 已载入 |
| 已连接但猫娘不动 | 确认 tModLoader 已载入配套 mod，看行为日志是否有报错 |
| 反复断开 | 检查端口 9877 是否被占用，mod 是否崩溃重启 |

### 行为相关

| 现象 | 解决方法 |
|------|---------|
| 任务卡住不继续 | 点「行为日志」看卡点，或直接问"你在干嘛" |
| 猫娘说"做不了" | 多半缺材料或附近没有对应的合成站/工作台 |
| 猫娘不动但在线 | 可能正在思考中（复杂任务需要规划时间），等几秒再看 |
| 挖矿效率低 | 确认猫娘持有合适的镐子，可说"换更好的镐" |

### Mod 相关

| 现象 | 解决方法 |
|------|---------|
| 已识别 mod 显示"暂无" | 需要重进游戏世界，猫娘会在进入时自动扫描 |
| 新装了 mod 但不认识 | 重进世界即可自动注册新 mod 物品 |
| 合成说找不到配方 | 配方数据来自 mod 扫描，确保对应 mod 已加载 |

## 端口与配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `server_host` | 127.0.0.1 | Terraria-Bot 服务端地址 |
| `server_port` | 7777 | Terraria-Bot 服务端端口 |
| `mod_host` | 127.0.0.1 | tModLoader mod 接口地址 |
| `mod_port` | 9877 | tModLoader mod 接口端口（需与 mod 设置一致） |
| `bot_name` | Neko | 猫娘玩家名 |
| `bot_skin` | 0 | 猫娘皮肤 ID |

> ⚠️ **重要**：修改 `mod_port` 后需同步修改 tModLoader 中 **NEKO猫娘AI** mod 的「监听端口」设置，否则连不上。

## 搭配使用

本插件是 N.E.K.O 平台的泰拉瑞亚扩展，需要以下组件配合：

```
N.E.K.O 平台（AI 大脑）
  └── neko_terraria 插件（本插件，桥接层）
        ├── Terraria-Bot 服务端（游戏协议）
        └── tModLoader + NekoTerrariaLink mod（精细动作）
              └── 泰拉瑞亚游戏世界
```

三者缺一不可。确保每一层都正常运行后，再从面板连接。
